# Panorama Korea - 프로젝트 계획서

## 1. 프로젝트 개요

### 1.1 프로젝트 목표
한국형 스마트 디스플레이 웹 애플리케이션을 개발하여 사용자가 날씨, 캘린더, 뉴스, 교통 정보를 한눈에 확인할 수 있는 통합 대시보드를 제공합니다.

### 1.2 참고 프로젝트
- **원본**: https://panorama-2ps.pages.dev/ (일본판 Panorama)
- **접근 방식**: 원본 디자인과 구조를 참고하되, 한국 API와 한국어로 재구축

### 1.3 프로젝트 레벨
**Dynamic Level** (Intermediate)
- BaaS 플랫폼 활용으로 빠른 개발
- 사용자 설정 저장 및 관리 기능
- 실시간 데이터 연동

## 2. 핵심 기능

### 2.1 날씨 정보 (Weather Widget)
- **데이터 소스**: 한국 기상청 공공 API
- **기능**:
  - 현재 날씨 (온도, 습도, 풍속)
  - 3일/주간 예보
  - 위치별 날씨 (사용자 설정)
  - 자동 업데이트 (10분 간격)

### 2.2 캘린더/일정 (Calendar Widget)
- **데이터 소스**:
  - 한국 공휴일 API
  - 음력 날짜 계산 라이브러리
  - bkend.ai (개인 일정 저장)
- **기능**:
  - 월간/주간 캘린더 뷰
  - 공휴일 자동 표시
  - 음력 날짜 병기
  - 개인 일정 추가/수정/삭제

### 2.3 뉴스 피드 (News Widget)
- **데이터 소스**:
  - 네이버 뉴스 RSS
  - 또는 뉴스 API 서비스
- **기능**:
  - 주요 헤드라인 5-10개 표시
  - 카테고리별 필터 (정치, 경제, IT 등)
  - 자동 업데이트 (30분 간격)
  - 뉴스 상세 링크

### 2.4 교통 정보 (Traffic Widget)
- **데이터 소스**:
  - 서울 열린데이터광장 API
  - 공공데이터포털 대중교통 API
- **기능**:
  - 지하철/버스 실시간 도착 정보
  - 주요 도로 교통 상황
  - 즐겨찾기 노선 설정
  - 자동 업데이트 (5분 간격)

## 3. 기술 스택

### 3.1 Frontend
- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: Zustand
- **Data Fetching**: TanStack Query
- **Date Library**: date-fns

### 3.2 Backend
- **BaaS**: bkend.ai
  - 사용자 설정 저장
  - 개인 일정 관리
  - (선택) 사용자 인증

### 3.3 External APIs
- 기상청 API (weather)
- 공휴일 API (calendar)
- 뉴스 API (news)
- 교통정보 API (traffic)

### 3.4 Deployment
- **Frontend**: Vercel
- **Backend**: bkend.ai (managed)
